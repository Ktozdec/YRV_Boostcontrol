# Firmware

В этой папке лежит прошивка ESP32 для проекта `YRV_Boostcontrol`.

## Основной файл

- `boost_controller_refined/boost_controller_refined.ino`

## Что делает прошивка

- управляет соленоидом бустконтроля по PID (gain scheduling, setpoint feed-forward, анти-windup)
- ведёт 2D-карту базового duty (TPS × RPM) с адаптивным самообучением
- читает MAP/TPS через ADS1115, считает RPM (прерывание) и скорость (PCNT по VSS)
- «обманка по бусту»: ограничивает MAP-сигнал на ECU через ЦАП MCP4725
- защищает мотор режимами SOFT_LIMP / HARD_LIMP
- отдаёт телеметрию по BLE (`YRV_Boost_BLE`) и принимает команды от Android-приложения
- слушает K-Line (listen-only) и шлёт ручные HEX-запросы по команде из приложения
- считает одометр и моточасы
- сохраняет параметры, карту и одометр в NVS
- поддерживает OTA через Wi-Fi AP `YRV_Boost_Pro`
- защищён watchdog'ом, общие данные под мьютексами

## Распиновка

- `25` — PWM соленоида (30 Гц)
- `18` — тахо (RPM, прерывание)
- `19` — VSS (скорость, PCNT)
- `23/22` — I2C SDA/SCL (ADS1115 + MCP4725)
- `16/17` — K-Line RX/TX (Serial2, 10400 бод)

## Библиотеки

- `Adafruit ADS1X15`
- `Adafruit MCP4725`
- `Preferences`
- `BLEDevice / BLEServer`
- `WiFi` + `WebServer` + `Update`

## Перед прошивкой

Проверь:

- правильную плату ESP32
- установленные библиотеки
- соответствие пинов реальному подключению (см. `docs/hardware/`)
- адреса I2C: ADS1115 `0x48`, MCP4725 `0x60`
- корректность калибровок датчиков после первого запуска (MAP авто-ноль на атмосфере выполняется при загрузке)
